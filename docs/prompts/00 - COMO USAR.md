# Como usar

1. Abra as pastas **na ordem dos números** (01, 02, 03…).
2. Dentro de cada pasta, faça os arquivos **na ordem dos números** (001, 002, 003…). Não pule.
3. Arquivo com **NOVA CONVERSA** no nome: abra uma conversa nova no gerador antes.
4. Copie o texto do arquivo, cole no gerador e **anexe o que o nome manda** ("anexar …").
5. Arraste a imagem gerada no **CONFERIR_ARTES.html**:
   - verde: salve com o nome do "salvar como";
   - vermelho: copie a frase de correção e cole no gerador.
6. Me mande as imagens prontas.
